# Jiban Niraula — GitHub Profile Setup

This folder contains a complete GitHub profile dashboard, not only a basic README.

## Files

```text
Jiban-Niraula/
├── README.md
└── .github/
    └── workflows/
        └── snake.yml
```

## 1. Create the special profile repository

Create a **public** GitHub repository named exactly:

```text
Jiban-Niraula
```

GitHub only displays a profile README when the repository name matches the username.

## 2. Copy the files

From inside this package:

- put `README.md` in the root of the new repository
- put `snake.yml` at `.github/workflows/snake.yml`

Then commit and push.

Example:

```bash
git clone https://github.com/Jiban-Niraula/Jiban-Niraula.git
cd Jiban-Niraula

# Copy README.md and .github/ from this package into the repo

git add .
git commit -m "feat: build GitHub profile dashboard"
git push origin main
```

## 3. Run the contribution snake once

On GitHub:

1. Open the `Jiban-Niraula` profile repository.
2. Open **Actions**.
3. Select **Generate Contribution Snake**.
4. Choose **Run workflow**.

The workflow creates an `output` branch containing the light and dark snake SVGs.

## 6. Recommended profile cleanup

A polished README works best when the rest of the profile agrees with it.

- Add concise descriptions to important repositories.
- Add repository topics such as `devops`, `docker`, `nginx`, `ansible`, `cicd`, `linux`.
- Archive or leave unpinned experiments that no longer represent your level.
- Improve READMEs of the six pinned repositories.
- Use meaningful commit messages.
- Keep GitHub Actions green where possible.
- Add architecture diagrams/screenshots to infrastructure repositories.
- Add `LICENSE` only where appropriate.
- Never commit `.env`, credentials, API keys, SSH keys or cloud secrets.
